# AI 塔罗互动 H5

这是一个可由 Codex 直接打开并继续开发的单页 H5 原型。

## 当前功能

- 用户输入真实问题
- 选择主题和困扰
- 三步交互式表单
- 随机抽牌与结果展示
- 免费分析与付费墙
- 模拟微信支付
- 完整行动报告
- AI 追问占位逻辑
- 分享卡与好友奖励

## 在 Codex 中打开

在 Codex 选择 GitHub 仓库：

`zanehu-ai/git-test`

然后进入目录：

`tarot/`

主页面：

`tarot/index.html`

## 本地运行

```bash
cd tarot
npm run dev
```

浏览器访问：

```text
http://localhost:3000
```

## 建议让 Codex 继续完成

可直接对 Codex 输入：

```text
请检查 tarot/index.html，将它重构为可维护的模块化前端项目，保留现有交互，并增加：
1. 真实 AI 对话接口占位；
2. 用户状态持久化；
3. 支付接口抽象；
4. 分享图片生成；
5. 埋点事件；
6. 移动端兼容测试。
```

当前支付与 AI 回复均为演示逻辑，不会产生真实扣款，也不会调用外部模型。
